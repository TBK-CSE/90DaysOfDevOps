1. Understanding of DevOps/cloud?
DevOps = mindset, not toolset. Deliver fast, reliable, automated. Field evolve fast → learn never stop, 20yr exp not matter, right approach matter.

2. Why start DevOps/cloud?
SSH into far machine = cool. Automate boring manual work = satisfying. Real goal: fast delivery, zero downtime, user never see pain.

3. Where want reach?
Master automation + scaling + zero-downtime systems. Build strong problem-solving. Design systems that run themselves, minimal manual touch.

4. How stay consistent?
Treat like daily habit — brush, eat, sleep, DevOps. Alarms/reminders enforce it. Missed day → catch up, no skip. 1-2hr/day outside job. Share solved problems on LinkedIn → accountability + visibility.

Current level: Working professional.

3 goals (90 days): Master automation. Ship scalable zero-downtime app. Deep Kubernetes.

3 core skills: Kubernetes, GitOps, Terraform.
